# VisaApplyHelp｜在美华人第三国签证步骤助手

VisaApplyHelp 帮助持中国护照、居住在美国的用户，把复杂的第三国签证申请拆成一条真正可以执行的路线。

它不是又一个让用户读完长文、再自己整理材料的攻略站。用户先确认当前美国身份，系统加载对应流程，然后通过 Checklist、官方入口和进度记录，从准备申请一直走到收到签证。

## 它解决什么问题

从美国申请加拿大、日本、韩国等第三国签证时，信息往往散落在政府网站、使领馆、签证中心和经验文章中。不同美国身份所需的证明材料也可能不同，而且“提交申请”通常只是整个流程的中点。

VisaApplyHelp 将这些信息组织为：

```text
确认身份
→ 加载适用流程
→ 准备信息与材料
→ 进入官方网站提交
→ 完成指纹、补件和护照递交
→ 收到并核对签证
```

用户始终知道自己在哪一步、下一步做什么，以及哪些内容来自官方。

## 面向谁

长期面向：

- 持中华人民共和国护照；
- 当前居住或合法停留在美国；
- 持 F、H、J、M、L 等非移民身份；
- 计划从美国申请第三国签证的用户。

0.1 版本聚焦一个足够具体、可以完整走通的案例：

> 年满 18 岁的中国护照 F-1 在读学生，从美国申请加拿大访客签证。

当前不覆盖美国公民、美国永久居民、复杂法律个案，也不提供代填、代交、代付款或材料托管。

## 核心价值

- **步骤化，而不是文章化**：把政策信息转化为可执行任务。
- **身份驱动**：根据用户美国身份加载对应配置，避免套用不适合自己的材料清单。
- **覆盖完整周期**：从申请准备持续到指纹、审理、贴签和收到护照。
- **官方来源优先**：关键步骤附政府或官方签证中心链接和核验日期。
- **隐私克制**：不保存护照号、申请号、银行资料、学校名称或申请文件。
- **可扩展**：新增国家和身份主要通过增加 FlowConfig，而不是复制页面。

## 当前能力

- F-1 身份确认与适用范围检查；
- 加拿大访客签证 16 步端到端流程；
- 必做、建议、条件适用和阅读确认四类 Checklist；
- 官方来源与外部申请入口；
- 浏览器本地进度保存；
- 日期级流程节点记录；
- 375px 移动端优先体验；
- sitemap、robots、页面 metadata 和隐私说明。

0.1 的时间线只保存在当前浏览器，不会上传服务器。

## 架构方向

项目使用 Next.js 14 App Router，采用模块化单体和可替换存储层：

```text
页面与组件
    ↓
领域逻辑
    ↓
Repository 接口
    ↓
localStorage（现在） / 登录用户数据库（未来）
```

当前不额外搭建 Express 后端。未来会在 Next.js 服务端加入认证、Data Access Layer 和 PostgreSQL 持久化，同时保留匿名本地使用与登录后认领进度的能力。

计划中的登录版本只保存：

- Flow ID 与版本；
- 当前步骤；
- Checklist 状态；
- 日期级时间线；
- 创建和更新时间。

不保存签证申请材料或官方账户信息。

完整产品和架构原则见 [docs/PROJECT_CORE.md](./docs/PROJECT_CORE.md)。

## 项目结构

```text
app/                    Next.js 页面和通用动态流程路由
components/             展示与交互组件
hooks/                  客户端流程状态协调
config/flows/           身份与签证流程配置
lib/domain/             与存储无关的纯领域逻辑
lib/repositories/       进度存储契约与 localStorage 实现
lib/persistence-models.ts 未来数据库记录契约
docs/                   产品、流程与核心指导文档
UPDATE.md               按时间倒序维护的修改记录
AGENTS.md               AI 与项目协作规范
```

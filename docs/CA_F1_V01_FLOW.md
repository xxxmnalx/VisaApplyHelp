# 加拿大访客签证 F-1 流程规格

> 产品版本：0.1  
> 文档状态：初稿，待逐项官方核验  
> 适用对象：中国护照、年满 18 岁、目前以 F-1 身份在美国学习的申请人  
> 流程终点：收到贴有加拿大签证的护照并完成信息核对  
> 更新日期：2026-06-23

## 1. 版本目标

0.1 只实现一条完整且可实际走通的路径：

> F-1 在读学生从美国在线申请加拿大访客签证（Temporary Resident Visa，TRV）。

用户进入网站后首先确认身份。系统随后加载 `ca-trv-f1-adult` 配置，并生成对应的步骤、Checklist、说明和官方链接。

本版本不追求支持所有美国身份，但实现方式必须允许未来通过新增配置支持 OPT、H、J、M、L 等身份，而不需要重写整个页面流程。

## 2. 适用范围

### 2.1 0.1 支持

- 持中华人民共和国普通护照
- 年满 18 岁
- 当前人在美国
- 当前为 F-1 在读学生
- 准备从零开始在线申请加拿大访客签证
- 旅游或普通短期访问目的
- 用户自行完成官方申请、缴费、预约和护照递交

### 2.2 0.1 暂不支持

- OPT、STEM OPT 或 F-2
- H、J、M、L、B 等其他美国身份
- 美国永久居民或美国公民
- 未满 18 岁
- 商务、探亲、医疗、人道等特殊访问目的
- 已经在中国递交申请、仅希望在美国贴签
- 使用代理人提交
- 纸质申请
- 拒签后重新申请或存在复杂犯罪、移民、医疗记录的个案

遇到不支持的情况时，系统应停止加载 F-1 默认流程，说明 0.1 尚未覆盖，并提供加拿大官方入口。

## 3. 身份优先的配置机制

### 3.1 入口顺序

```text
确认中国护照
→ 确认当前人在美国
→ 选择美国身份
→ 确认年龄和申请状态
→ 加载身份配置
→ 进入对应国家与签证流程
```

0.1 中只有选择 F-1 且符合其他范围条件的用户可以继续。

### 3.2 配置 ID

```text
ca-trv-f1-adult
```

建议配置至少包含：

```ts
type FlowConfig = {
  id: string;
  version: string;
  country: "CA";
  visaType: "visitor";
  status: "F1";
  minimumAge: number;
  lastVerified: string;
  eligibility: EligibilityQuestion[];
  steps: FlowStep[];
  sources: OfficialSource[];
  timelineEvents: TimelineEventDefinition[];
};
```

页面组件只消费配置，不直接写入 F-1 专属材料名称。未来新增身份时，优先新增配置或覆盖项。

## 4. 端到端流程

```text
0. 身份确认
1. 适用性检查
2. 查看流程总览
3. 准备个人与旅行信息
4. 准备申请材料
5. 创建或进入 IRCC 账户
6. 填写在线申请
7. 上传材料、核对、缴费并提交
8. 等待并处理生物信息采集通知
9. 完成生物信息采集
10. 等待审理并处理补充要求
11. 收到护照递交通知
12. 向加拿大签证申请中心递交护照
13. 跟踪护照处理与返还
14. 收到护照并核对签证
15. 可选提交匿名时间线
```

## 5. 各步骤规格

### Step 0：确认身份

目标：在流程开始前加载正确配置。

问题：

- [ ] 我持中国护照。
- [ ] 我目前人在美国。
- [ ] 我的当前身份是 F-1。
- [ ] 我目前仍为在读学生，而不是 OPT。
- [ ] 我已年满 18 岁。
- [ ] 我准备提交一份新的加拿大访客签证申请。

完成条件：所有答案符合 0.1 范围。

不符合时：

- 不进入默认 Checklist。
- 提示该身份或情况将在后续版本支持。
- 提供加拿大官方访客签证页面。

### Step 1：适用性检查

目标：帮助用户发现明显不适合标准流程的情况，但不代替签证资格判断。

确认项：

- [ ] 护照有效，且计划使用该护照申请和旅行。
- [ ] 访问目的属于短期旅游或普通访问。
- [ ] 计划在访问结束后离开加拿大。
- [ ] 能够说明自己在美国的学习安排及返回约束。
- [ ] 能够承担旅行和申请费用。
- [ ] 没有需要专业意见处理的复杂拒签、犯罪、移民或健康情况。

加拿大官方列出的基本要求包括有效旅行证件、足够资金、离境意图，以及让签证官相信申请人具有会促使其离开的联系。本站只能提醒用户核对这些要求，不能判断一定符合资格。

### Step 2：流程总览

向用户展示：

- 当前配置：F-1 在读学生
- 签证类型：加拿大访客签证（TRV）
- 申请方式：在线申请
- 主要阶段：申请准备、在线提交、生物信息、审理、护照递交、收到签证
- 官方申请费：由配置读取最近核验值
- 生物信息费：根据是否需要采集，由配置和官方判断入口说明
- 官方处理时间查询入口
- 本站用户时间线：数据不足时显示“数据收集中”
- 最近核验日期

注意：处理时间不是承诺，也不包含所有生物信息预约、补件和护照往返耗时。

### Step 3：准备个人与旅行信息

用户在打开官方申请系统前准备：

- [ ] 护照信息和过往护照信息
- [ ] 中国身份证信息（如官方表单要求）
- [ ] 当前美国住址和联系方式
- [ ] 学校及当前学习信息
- [ ] 预计入境和离开加拿大日期
- [ ] 旅行目的和简短行程
- [ ] 过去的教育、工作和旅行经历
- [ ] 配偶、子女和父母等家庭信息
- [ ] 既往加拿大申请或入境记录
- [ ] 既往拒签或移民记录（如有，必须如实回答）

本站不保存上述具体内容，只提供准备清单。

### Step 4：准备申请材料

最终材料必须以用户在 IRCC Portal 中获得的个性化文件清单为准。

#### 核心材料

- [ ] 当前有效中国护照的清晰彩色扫描件
- [ ] 护照中带有签证、印章或其他标记的页面
- [ ] F-1 身份证明，例如有效 I-20
- [ ] 美国入境或身份记录，例如 I-94
- [ ] 学校在读证明
- [ ] 旅行目的及行程说明
- [ ] 资金证明
- [ ] 符合官方要求的电子照片（如个性化清单要求）

#### 条件材料

- [ ] 旧护照及相关签证、出入境记录
- [ ] 既往旅行记录
- [ ] 邀请信及关系证明
- [ ] 解释信
- [ ] 资助人的资金和关系证明
- [ ] IRCC 个性化清单要求的其他表格或文件

#### 每项材料的交互

每项展开后显示：

- 官方要求或本站建议
- 为什么可能需要
- 建议包含哪些信息
- 文件清晰度和合并提示
- 常见遗漏
- 官方来源
- “已准备”“暂时跳过”“不适用”

不得把第三方经验中的固定余额、固定文件数量或固定格式写成官方保证。

### Step 5：创建或进入 IRCC 账户

页面提供加拿大官方申请入口，并说明 IRCC 可能提供不同账户或 Portal 路径，用户应根据官方当前指引选择。

Checklist：

- [ ] 已从本站提供的加拿大政府官方页面进入。
- [ ] 已确认自己选择的是 visitor visa。
- [ ] 已创建账户或成功登录。
- [ ] 已安全保存自己的登录和恢复方式。
- [ ] 已确认官方系统生成的个性化材料清单。

跳转提示：

> 你即将进入加拿大政府官方系统。本站不会读取你的账户、申请表或上传文件。

### Step 6：填写在线申请

本站按主题提醒用户，但不复制官方问题或代填答案：

- [ ] 旅行计划
- [ ] 个人和护照信息
- [ ] 美国居住和身份信息
- [ ] 教育与工作经历
- [ ] 旅行历史
- [ ] 财务信息
- [ ] 家庭信息
- [ ] 安全、医疗和移民背景问题
- [ ] 联系方式

提示原则：

- 所有答案必须真实、完整并与证明文件一致。
- 不确定如何回答涉及拒签、犯罪、移民违规或身份问题时，应查看官方说明或咨询合格专业人士。
- 本站不记录用户答案。

### Step 7：上传、核对、缴费并提交

Checklist：

- [ ] 已上传个性化清单要求的全部文件。
- [ ] 文件清晰、方向正确且可以打开。
- [ ] 表单内容与护照、I-20 等文件一致。
- [ ] 已检查姓名、日期和证件号码。
- [ ] 已阅读声明并完成官方电子签署。
- [ ] 已按官方页面显示金额缴费。
- [ ] 已成功提交申请。
- [ ] 已保存提交确认和缴费收据。

时间线记录点：

```text
applicationSubmittedAt
```

### Step 8：等待生物信息采集通知

用户提交后：

- [ ] 已定期查看 IRCC 账户。
- [ ] 已查看邮箱及垃圾邮件。
- [ ] 已确认是否收到 Biometrics Instruction Letter（BIL）。
- [ ] 已通过官方工具核对既往生物信息是否仍有效。

如果收到 BIL，进入 Step 9。若官方确认无需采集，则标记不适用并进入 Step 10。

时间线记录点：

```text
biometricsLetterReceivedAt
```

### Step 9：完成生物信息采集

加拿大官方要求收到 BIL 后尽快预约；官方页面说明通常需要在 BIL 给出的期限内完成，目前一般为收到后 30 天，最终以用户信件为准。

Checklist：

- [ ] 已阅读 BIL 中的地点和截止日期。
- [ ] 已通过官方入口预约美国境内可用采集点。
- [ ] 已保存预约确认。
- [ ] 已准备护照、BIL 和预约确认等现场要求文件。
- [ ] 已完成指纹和照片采集。
- [ ] 已在 IRCC 账户中确认状态后续更新。

时间线记录点：

```text
biometricsCompletedAt
```

### Step 10：等待审理和处理额外要求

Checklist：

- [ ] 定期查看 IRCC 账户和邮箱。
- [ ] 收到补件、面试、体检或其他要求时，按通知处理。
- [ ] 没有把官方预计处理时间理解为最长时限或批准保证。

分支：

```text
收到额外要求
├── 是：记录类型、截止日期和完成状态
└── 否：继续等待决定
```

本站只记录任务状态，不保存补充文件或通知内容。

### Step 11：收到护照递交通知

在线申请获批后，IRCC 会在账户中提供护照递交说明。用户在收到正式通知前不应寄出护照。

Checklist：

- [ ] 已在 IRCC 账户中收到正式护照递交通知。
- [ ] 已确认通知中的截止日期。
- [ ] 已确认需要递交的是申请时使用的同一本护照。
- [ ] 已阅读美国加拿大签证申请中心的最新递交要求。

时间线记录点：

```text
passportRequestReceivedAt
```

### Step 12：向 VAC 递交护照

本步骤的费用、地址、付款方式、回邮方式和所需表格变化较频繁，必须由独立配置读取，并在页面显示“最近核验日期”。

Checklist 框架：

- [ ] 护照原件
- [ ] IRCC 护照递交通知
- [ ] VAC 当前要求的同意书
- [ ] 当前适用的服务费或传递费
- [ ] 当前适用的寄送或现场递交方式
- [ ] 回邮安排
- [ ] 已保留快递单号、收据和材料副本

页面不得依据旧攻略硬编码 VAC 地址、费用或付款方式。每次发布前从 VFS Global 美国加拿大签证申请中心官方页面核验。

时间线记录点：

```text
passportSubmittedAt
```

### Step 13：跟踪护照处理与返还

Checklist：

- [ ] 已确认 VAC 收到护照。
- [ ] 已保存 VAC 或快递追踪信息。
- [ ] 已查看 IRCC 账户状态。
- [ ] 已确认护照开始返还。

时间线记录点：

```text
passportReturnShippedAt
```

### Step 14：收到护照并核对签证

Checklist：

- [ ] 已收到护照。
- [ ] 护照没有运输损坏。
- [ ] 签证姓名与护照一致。
- [ ] 护照号码正确。
- [ ] 签证类别正确。
- [ ] 入境次数和有效期已经核对。
- [ ] 已保存申请收据和决定记录。
- [ ] 已理解签证不保证入境，最终由加拿大边境官员决定。

时间线记录点：

```text
passportReceivedAt
```

流程完成条件：用户确认收到护照并完成签证信息核对。

### Step 15：可选匿名时间线

完成后邀请用户提交短问卷：

- 申请提交日期
- BIL 收到日期
- 生物信息完成日期
- 护照递交通知日期
- 护照递交日期
- 护照收到日期
- 所在州
- 是否首次采集加拿大生物信息
- 最终结果

提交前明确说明：

- 问卷自愿。
- 不填写姓名、邮箱、护照号、UCI 或申请号。
- 数据仅用于生成聚合时间统计。
- 官方处理时间与本站样本统计会分开显示。

## 6. 时间统计定义

建议计算：

```text
总耗时 = 收到护照日期 - 在线提交日期
等待 BIL = BIL 收到日期 - 在线提交日期
生物信息后审理 = 护照递交通知日期 - 生物信息完成日期
贴签与返还 = 收到护照日期 - 护照递交日期
```

展示规则：

- 默认展示中位数。
- 同时显示样本量和第 25 至第 75 百分位区间。
- 建议至少有 10 条有效完成样本后才公开统计。
- 拒签、撤回和未完成申请不进入“收到签证总耗时”。
- 缺少关键日期的样本只参与其可计算阶段。
- 标记明显无效、倒序、重复或异常数据。
- 不将本站统计描述为预测或保证。

## 10. 待核验与待决策

- F-1 0.1 是否只覆盖“旅游”，还是包含无邀请人的普通短期访问。
- IRCC Portal 与 IRCC Portal New Version 的实际分流条件和页面文案。
- F-1 核心材料中哪些属于官方固定要求，哪些只是常见推荐材料。
- 美国 VAC 当前护照递交方式、地址、服务费、付款与回邮要求。
- 是否在 0.1 实现问卷提交后端，还是只实现完成页与问卷原型。
- 时间线样本公开阈值是否采用 10 条，后续是否提高到 20 或 30 条。
